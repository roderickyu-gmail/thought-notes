# 顶级思想目录创作要求

- 本目录用于保存独立成篇的思想类文章，每篇文章优先做成可直接打开的静态 HTML 文件。
- 文章内容可从用户提供的中文图片或文字中提取，并在需要时翻译成地道、自然、适合英文读者阅读的英文。
- 每篇文章需要补充一个清晰、有设计感、能概括核心观点的英文标题。
- HTML 阅读风格应保持易阅读、简洁、清晰、大方，并带有木质感的视觉气质。
- 设计重点是正文可读性：字号、行高、留白、对比度和移动端适配必须优先于装饰。
- 不要扩展成营销页或复杂站点；每篇文章应是一个独立、克制、专注阅读的文章页面。
- 新增或修改文章时，同步检查文件标题、页面 `<title>`、正文结构和样式是否与本目录定位一致。
