# Top Insights Directory Guidelines

- This directory stores standalone reflective essays. Each essay should preferably be a static HTML file that can be opened directly in a browser.
- Source material may come from Chinese text or images provided by the user, and should be translated into natural, idiomatic English when needed.
- Each article needs a clear, well-crafted English title that captures the central idea.
- The HTML reading style should be simple, clear, elegant, and easy to read, with a restrained wood-inspired visual tone.
- Readability comes first: typography, line height, spacing, contrast, and mobile layout matter more than decoration.
- Do not expand these essays into marketing pages or complex websites. Each page should stay focused, quiet, and article-first.
- When adding or editing an article, check that the filename, page `<title>`, content structure, and visual style match the purpose of this directory.
